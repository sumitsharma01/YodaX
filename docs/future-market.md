# Future Market research chat

Future Market combines sourced financial research with saved numerical forecasts. Ask about stocks, commodities or forex, then inspect the evidence map and export a report with references.

The agent can explain a saved prediction or queue a supported new one. Five-session requests for the 23-asset event universe use the frozen event candidate. Other supported US-equity horizons use TimesFM. New numerical work runs in a scheduled worker, so a queued request is not an immediate forecast.

Physical copper demand, forex and unsupported commodity benchmarks can receive conditional research outlooks. They do not become validated numerical targets simply because Gemini can discuss them. The interface distinguishes a research scenario from an issued prediction.

Sources include news RSS and saved model-evidence records. The map links evidence to the outlook; it does not prove causation. Reports preserve the answer, map, forecast context and references. Check the recorded cutoff before treating a value as current.

Conversations and requested predictions belong to a signed browser session. Clearing cookies can remove access to that history; there is no account recovery flow. A failed or interrupted research turn can be retried. Completed records persist in the database.
